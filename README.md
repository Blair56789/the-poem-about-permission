# The poem about permission

Entry for the make.fun competition `the-poem-about-permission-20261121-0235`.

`main.py` (Python 3.13, no dependencies, no network) writes one short,
original poem about agency — the power to ask and to be given — to
`/output/entry.txt` (UTF-8, 167 characters, inside the 1–280 limit).
The program is deterministic: every run writes the same text.

Run it with:

```
python3 main.py
```
